02 / How it works

Three steps. One command.

  1. 01

    Checkpoint

    Skeptic reads the session you pick: your last request, the files it changed, and the project's own notes. Only folders you approved, nothing else.

  2. 02

    Choose

    Pick the window and the engine: Codex, Hermes, or Claude again once it's back. Every open session is listed separately, so the ones you're saving stay put.

  3. 03

    Continue

    The new engine gets the handoff and carries on in the same folder. Your original Claude session stays intact, so you can go back to it.

03 / Built to be trusted

Skeptical by name. Careful by design.

  • Reads only what you approve

    The first switch in a project asks you to type approve. Take it back any time with skeptic permissions revoke.

  • Runs on your Mac

    No account, no server, no telemetry. Skeptic makes no network calls. The engines you switch to use their own sign-ins.

  • Never ships for you

    No commits, pushes or deploys. It hands over the work and stops. What happens next is your call.

  • Says what it can't see

    Unsaved work and hidden reasoning can't be recovered, and Skeptic says so in the handoff instead of guessing.

  • Open source

    MIT licensed. Read every line, including the install script, before you run it.

  • Proven on a real switch

    On 12 October 2026 a live Claude session out of quota was handed to Codex, which carried on correctly.

05 / Install

Two minutes, no admin rights

You need

  • A Mac (Linux should work but is untested)
  • Python 3.9 or newer and Git (xcode-select --install gives you both)
  • At least one engine to switch to: Codex, Hermes or Claude Code, signed in

Then

  1. Install with one of the commands above.
  2. Open a new Terminal window.
  3. When Claude stops, press Ctrl+Z and run skeptic.

Safe by construction

  • The one-line installer checks the download's SHA-256 checksum and stops if it doesn't match.
  • Everything stays in your home folder: the app in ~/.local/share/skeptic, the command in ~/.local/bin, one marked line in ~/.zshrc, and the /skeptic helpers for Claude Code and Codex.
  • It only replaces files it put there itself. If you've changed one, it stops and tells you which.

Remove it

brew uninstall skeptic        # Homebrew
rm -rf ~/.local/share/skeptic ~/.local/bin/skeptic   # one-line install
rm -rf ~/.claude/skills/skeptic ~/.agents/skills/skeptic ~/.skeptic-cli

Last, delete the two lines under # Skeptic terminal PATH in ~/.zshrc if they're there.

07 / Questions

Fair questions

Is it really free?

Yes. Skeptic is open source under the MIT license. You only pay for the AI engines you already use.

Does Skeptic read my conversations?

Only the session you choose to switch, and only after you approve it. It reads the requests and progress in that session's local transcript, never hidden reasoning, and nothing leaves your Mac except the handoff you give the next engine.

What happens to my Claude session?

Nothing. It stays open and intact. Switch back when your limit resets.

Does it need Codex?

It needs at least one other engine to hand over to. Codex, Hermes and Claude Code all work, and local models run through Codex.

Is it affiliated with Anthropic, OpenAI or Nous Research?

No. Skeptic is an independent project that works with their tools. Their names belong to them.
