Privacy

The Skeptic app

  • Skeptic runs on your Mac. It has no account, no server and no telemetry, and it makes no network calls.
  • It reads only the folders you approve, and only when you switch. Approvals and project mappings are stored on your Mac in ~/.skeptic-cli. Remove an approval with skeptic permissions revoke PATH, or delete that folder to remove everything.
  • An optional activity log is off by default. If you turn it on, it stays in that same folder and is never sent anywhere.
  • When you switch, Skeptic gives the handoff to the engine you picked (for example Codex). What that engine does with it is governed by that provider's own terms and privacy policy.

This website

  • No cookies, analytics, trackers, forms or third-party scripts. The page's security policy blocks them outright.
  • The site is hosted on Cloudflare Pages, which, like any web host, handles standard request data (such as your IP address) to serve and protect the site.
