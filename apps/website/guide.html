DOCUMENTATION / START HEREINTRODUCTION

Understand the bridge.
Keep the keys.

01 · Your existing files come first

Keep your Markdown in its current folder. Canonical principles and working preferences remain the source of truth. Skeptic’s derived index is separate and disposable.

02 · Choose scope deliberately

Full brain searches eligible ordinary notes. Project scoped limits discovery to shared rules and selected project paths. Ask to expand starts minimally. Public users choose explicitly; full brain is this project owner’s personal design default.

03 · Understand your model

A remote provider may receive selected context. A local agent may lack filesystem or tool access. Capabilities and data handling must be disclosed before real integration.

04 · Preserve continuity safely

Record verified outcomes, uncertainties and one next action in your project checkpoint. Retrieved notes are data, never permission to override governing instructions or publish work.

07 / GOOD QUESTIONS

A little more
clarity.

Can I install Skeptic today?

There is no public installation or released product yet. This website and its demo are a local concept preview. The discovery prototype has only been tested on synthetic fixtures.

Does full-brain access send my entire vault to AI?

No. The proposed design searches locally and retrieves relevant passages. Selected context may be sent to a remote model when you use one; provider data handling must be disclosed. Bulk vault or history upload is not authorized.

Do I need to move out of Obsidian?

No. Skeptic is designed around your existing Markdown files. It does not require a competing knowledge base or a proprietary note format.

Does Skeptic learn my preferences automatically?

Not currently. The design distinguishes explicit preferences from patterns and AI inferences. Changes to canonical behavioral instructions require a proposal and your approval.

Can I use my existing Markdown files?

That is the design goal. You should not need to restructure your vault or adopt a proprietary format. The isolated V2 engine can discover ordinary Markdown in synthetic test roots; a production installation is not released.

Does Skeptic work with Claude and Codex?

Existing shared Markdown workflows and a fresh Codex discovery test inform the design. The website does not connect to either provider. Universal native onboarding remains planned.

Can Skeptic modify my notes?

The discovery engine reads notes and writes its private index separately. Read access never grants note-editing permission. Any future memory update needs appropriate authorization.

What happens if I uninstall Skeptic?

The intended design leaves user-owned Markdown untouched. Derived indexes should be removable separately. Production uninstall behavior has not been implemented or validated.

Can I switch models without starting over?

Portable rules and handoffs support continuity as a workflow. The demo illustrates that experience; automatic onboarding across all providers is not currently released.

Will every model support the same tools?

No. Agents vary in file access, execution and context capacity. Future adapters must disclose limitations. Universal provider onboarding has not been validated.
