WELCOME TO SKEPTIC

Your work. Your memory. Any AI.

Switch AI agents without starting over.

Skeptic is not another AI subscription. It connects the tools you choose and helps preserve your work between them.

  1. Connect a knowledge source below. Obsidian is optional; an existing Markdown folder or Git project works too.
  2. Approve exactly what Skeptic may read. Registered folders persist; read approval is renewed each app session.
  3. Use the terminal switcher to continue with an installed agent. Claude Code and Codex are supported destinations; other integrations are planned.

Commands & help

Enter these commands in a normal Terminal shell, not inside a running AI interface. The CLI works independently of this app.

skeptic
skeptic doctor
skeptic models
skeptic status
skeptic sessions --project "$HOME" --title "Email contact with Boris"
skeptic session handoff --project "$HOME" --title "Email contact with Boris"
skeptic session continue --project "$HOME" --title "Email contact with Boris" --with codex
skeptic catchup --with claude
skeptic continue --with claude

Keep your original Claude window open. Its /skeptic helper guides a second-Terminal workflow; it cannot replace Claude’s running TUI. Session access requires explicit approval and handoff review.

Connect Obsidian using the vault source type, an existing Markdown folder using Additional project location, or Git using the repository source type. No external tools or accounts are installed automatically. Hermes and other future agents are not integrated.

Portable skills remain a future feature: Learn → Propose → Approve → Reuse.

Knowledge & permissions

FULL_BRAIN searches eligible Markdown locally inside approved roots. PROJECT_SCOPED limits body reads to discovered project folders and instructions. ASK_TO_EXPAND reads checkpoints and instructions only. Expansion requires a new explicit root/policy approval.

Claude Code / Codex / APIs: not connected. Automatic synchronization and memory updates: unavailable.

Only local registration settings are written. Removing a discovered project hides it for this session. Disconnect a root in Permissions to revoke all access to its files. Saved roots require fresh approval after restart. Your Markdown is never edited.
