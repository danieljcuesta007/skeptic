# Skeptic brand — v1, 12 Oct 2026

*Not everything is black and white.* A DC Labs product.
Full guide: [skeptic-brand-guide.png](skeptic-brand-guide.png).

| File | Use |
| --- | --- |
| `skeptic-hood.svg` | **Primary mark** (white). Every small placement: widget title, favicon, menu bar, terminal. Minimum 14pt. |
| `skeptic-hood-ink.svg` | The hood in ink (#0B0B0C) for light backgrounds. |
| `skeptic-hood-halftone.svg` | **Display mark**. Large placements only, 48pt and up: window headers, app icon, cover art. |
| `skeptic-icon.svg` | App icon / favicon: ink squircle, white hood. |

- **Colour:** Ink #0B0B0C, Paper #F7F7F7, White (only what can switch), Grey #8C8C8C (waiting), Graphite #3D3D3D (unclear). No brand colour.
- **Type:** serif (New York / Georgia) for names and the wordmark; SF Mono tracked caps for labels; SF Pro for sentences.
- **Lockups:** horizontal (hood + "Skeptic"), stacked (halftone hood over the wordmark), endorsed ("A DC Labs product").
- **Don't:** colour the mark, stretch or tilt it, or use the halftone under 48pt.
- **Terminal:** `skeptic` prints the hood (block characters) above its menu.

The same geometry is drawn in code by the Vitals widget (`SkepticMark` in ai-search-tracker).
