# Security — pre-alpha

Do not use this prototype with sensitive production notes. Report potential defects
privately using an agreed channel; no public reporting address is established yet.
Use synthetic reproductions and sanitized logs. Never send notes, tokens or credentials.

Known limits: trusted host policy, plaintext derived index, incomplete hostile-cache
schema/DoS and filesystem-race defenses, imperfect secret heuristics and no OS sandbox.
Instruction references and role labels cannot guarantee model compliance. Revalidation
must be invoked immediately before consequential host actions; no action host is
integrated. See docs/security/REVIEW.md. Independent security acceptance remains pending.
